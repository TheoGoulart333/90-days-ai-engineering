# Generative AI

## What is Generative AI

Generative AI is a category of artificial intelligence focused on creating new content, such as text, code, images, or responses in natural language. In the context of this Microsoft Learn path, the focus is on applications that use language models to interact with users and support useful workflows.

## Core concepts

- Language models generate responses from prompts and conversation context.
- Model selection should match the use case, expected behavior, and evaluation criteria.
- Deployment exposes a selected model through an endpoint that applications can use.
- Evaluation helps compare model behavior and validate whether responses meet expectations.
- Tools allow generative AI applications to interact with external systems or perform actions beyond basic chat.
- Prompt engineering, retrieval augmented generation, and fine-tuning are optimization strategies with different trade-offs.
- Responsible AI practices help reduce harmful, unsafe, or unreliable behavior.

## When to use

Generative AI is useful when an application needs to interact through natural language, generate or transform content, assist users with complex information, or combine language understanding with external tools and data.

It should be used carefully when the output needs grounding, traceability, or strong reliability requirements. In those cases, evaluation, retrieval strategies, and responsible AI controls become part of the engineering work.

## Practical applications

- Chat applications that interact with users through natural language.
- Assistants that combine model responses with external tools.
- Applications that use retrieval augmented generation to ground responses in relevant data.
- Workflows that evaluate and improve model behavior before release.
- Responsible AI implementations that reduce harmful or unreliable outputs.

## Main learnings from this Learning Path

- Building generative AI applications requires more than prompt writing; it involves planning, model selection, deployment, evaluation, optimization, and responsible implementation.
- Microsoft Foundry provides a development environment for working with models, endpoints, tools, and evaluation workflows.
- Prompt engineering, RAG, and fine-tuning should be selected based on the specific behavior the system needs.
- Tool use can extend a generative AI application, but it should be introduced intentionally and tested carefully.
- Responsible AI is part of the application design and should be considered before deployment.
