# Contributing

Thank you for your interest in **90 Days of AI Engineering**.

This repository is primarily a personal learning log, but thoughtful feedback, corrections, references, and ideas are welcome. The standard for contributions is the same as the standard for the journey: useful, specific, and honest.

## Good contributions

- Correcting a factual or technical error
- Suggesting a stronger reference or a missing caveat
- Improving clarity, accessibility, or organization
- Sharing a reproducible improvement to a project or experiment

## Documentation conventions

- Write in clear, natural English unless the context requires another language.
- Keep daily entries factual: record what was actually studied or built.
- Link evidence when it exists; do not add placeholder achievements.
- Explain limitations and failed approaches when they are useful to the reader.
- Use the [day template](templates/day-template.md) as a starting point.

## Pull requests

Please describe the problem, the proposed change, and how it was checked. Keep pull requests focused and avoid unrelated formatting changes.

## Code of conduct

Be respectful, constructive, and precise. Disagreement is welcome; personal attacks are not.
